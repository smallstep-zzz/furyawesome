## 웹사이트 자동 반영

`catalog.json`은 OpenFury Hub가 읽는 공개 색인입니다. 모델 게시기는 `models/*.json`, `catalog.json`, 아래 README 목록을 **한 번의 GitHub 커밋으로** 갱신합니다. 웹사이트는 이 JSON을 주기적으로 읽으므로 모델이 추가돼도 별도 사이트 배포가 필요 없습니다.
